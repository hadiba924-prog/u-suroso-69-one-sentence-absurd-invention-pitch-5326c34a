## The pitch

A shower curtain that puffs itself into a bubble wall mid-shower so it stops clinging to your legs like a needy ghost.

One sentence, 118 characters — an absurd invention for an everyday annoyance everyone recognises instantly.

## How to run

```sh
node main.ts
```

Running `main.ts` writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Why it works

The best absurd inventions start from a real irritation. Everyone who has showered has fought a clinging curtain; inflating it into a bubble wall turns that daily annoyance into something playful, visual, and instantly imaginable — absurd, but only just.
