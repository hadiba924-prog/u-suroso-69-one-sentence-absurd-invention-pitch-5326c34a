One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: the shower curtain that will not stop clinging to your legs mid-shower. Entry by Aldi Sopa (@aldi-sopa).

## The pitch

> A shower curtain that puffs itself into a bubble wall mid-shower so it stops clinging to your legs like a needy ghost.

## How to run

```sh
node main.ts
```

This writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline.
